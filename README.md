# Emergency Dispatch & Traffic Analysis

This project analyzes a synthetic **Emergency Dispatch & Traffic Physics dataset** containing 200,000 traffic observations from 2022–2025. The goal was to explore traffic patterns, driver behavior, accident risk, and emergency response times.

### What We Did
- Cleaned and prepared the dataset using Python and Pandas.
- Performed **Exploratory Data Analysis (EDA)** to identify trends and patterns.
- Analyzed the impact of weather, road type, congestion, and time of day on accidents.
- Investigated accident severity and emergency response times.
- Created data visualizations and an **interactive dashboard** to communicate key findings.

### Key Findings
- Congestion was highest in urban areas and during peak hours.
- Accident rates increased under poorer weather conditions.
- Interstate roads had the highest accident rate.
- Motorcycle accidents had a significantly higher proportion of severe or fatal outcomes.
- Actual emergency response times exceeded the stated baseline in most accident cases.

The project demonstrated how data cleaning, exploratory analysis, visualization, and dashboards can be used to turn complex traffic data into actionable insights.
